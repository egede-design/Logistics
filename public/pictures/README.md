# Entity logo

Place the organization's logo image in this folder and name it `logo.png`.
The system automatically displays `/pictures/logo.png` instead of the `IR`
placeholder. Use a square or horizontal logo with a transparent or white
background for best fit. Refresh the application page after replacing the
image. PNG is recommended.

The sign-in page also uses the original `healthcare-background.svg` artwork in
this folder as a subtle, low-opacity health illustration. It is separate from
the entity logo and does not need to be changed when adding your logo.
